# 多城深度旅行运营服务

这是一个服务于文旅运营方、县域目的地、交通协作方和在地体验供应商的 Python 后端。服务使用 FastAPI 与 SQLite 管理旅行产品、目的地节点、运营材料、游客反馈、参数化行程方案、待执行任务、节点租约、失败恢复、观察记录版本和人工干预。所有运行状态保存在单个本地数据库文件中，不需要另行部署数据库、缓存、消息队列或浏览器界面。

## 已有能力

- 产品目录：登记多城章节线路、县域慢游、自然村寨、非遗工坊、夜游演艺和交通联运产品。
- 节点目录：维护景区服务站、县域接待点、交通枢纽、文化场馆和社区合作点的能力与并发上限。
- 运营材料：按产品保存线路、运力、安全、授权和游览材料，使用内容摘要实现重复提交幂等，并支持接受或驳回。
- 游客反馈：按节点、行程引用和受众类型保存评分、标签、意见以及后续联系授权，重复反馈不会创建第二条记录。
- 行程方案：使用参数规则描述跨城换乘、章节式游线、县域慢游、常态夜游和亲子体验的运行边界。
- 任务调度：提交方按项目和幂等键创建行程任务，执行节点按能力领取并获得有期限的租约。
- 执行回执：节点可以续租、提交观察记录或报告失败；可重试失败按照确定的退避时间重新排队。
- 失败恢复：租约到期后由恢复入口重新排队，达到最大尝试次数的任务转为失败。
- 人工干预：取消、人工重试、优先级调整和批量操作均保留操作者、原因、前后状态与批次标识。
- 身份审计：保留用户、角色、团队、会话、权限、审计事件和后台维护能力，敏感凭据只保存摘要。

## 运行环境

- Python 3.11
- SQLite 3，由 Python 标准库提供
- Linux、macOS 或 Windows

## 安装

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -e ".[dev]"
```

默认数据库位于 `./data/deep-travel.db`。可复制 `.env.example`，并通过 `DEEP_TRAVEL_DATABASE_PATH` 指定其他本地文件。

## 数据库初始化与检查

```bash
python -m app.cli init-db
python -m app.cli check-db
python tools/verify_sqlite.py
```

## 启动 API

```bash
uvicorn app.main:app --host 0.0.0.0 --port 8432
```

服务状态检查：

```bash
curl -sS http://127.0.0.1:8432/api/system/health
```

产品、节点、运营材料和游客反馈接口使用 `/api/catalog` 前缀，行程方案、任务、领取、回执与恢复接口使用 `/api/pilots` 前缀。

## 测试与编译检查

```bash
python -m pytest
python -m compileall -q app tests tools
```

测试覆盖身份与审计、产品和节点登记、材料重复提交、材料审阅、反馈幂等、参数校验、任务提交、优先级领取、能力匹配、租约续期、失败退避、观察版本、取消、人工重试、批量操作和租约恢复。

## API 与命令行冒烟

```bash
python -m app.cli smoke
python -m app.cli pilot-demo
```

`smoke` 在进程内检查根路径和服务状态接口。`pilot-demo` 会登记一条网文 IP 章节线路和一个古城接待节点，创建跨城换乘节奏方案，提交并领取行程任务，用于快速确认目录与运营链路。

## 目录结构

```text
app/
  catalog/          文旅产品、目的地节点、运营材料与游客反馈
  pilots/           行程方案、任务、租约、观察记录和人工干预
  api/              用户、角色、团队、认证、审计和系统接口
  core/             时钟、安全、隐私、异常与分页
  repositories/     身份、审计和团队数据访问
  services/         身份、后台任务、维护和通用服务
  cli.py            初始化、检查和冒烟入口
  database.py       SQLite 连接、事务、表结构与基础权限
tests/               核心、目录、运营和身份回归测试
tools/               数据库完整性检查
```

## 数据一致性

SQLite 连接启用外键、WAL、busy timeout 和同步写入策略。产品目录、材料审阅、反馈提交、任务领取、执行回执与人工干预使用即时事务；领取通过条件更新避免同一任务被重复分配。服务保存 UTC 时间字符串，测试可注入固定时钟验证退避、租约到期和跨日配额。审计记录会清理密码、令牌等敏感字段，游客反馈仅保存联系人摘要和是否允许后续联系。
